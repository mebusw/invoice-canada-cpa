# invoice-canada-cpa

[English](README.md) · [中文](README.zh-CN.md)

一个 Agent Skill：把一堆加拿大收据、发票照片，变成 CPA 能直接用的、明细级、可审计的费用工作底稿 —— 每一行都带上用于 T2 申报的 CRA GIFI code。

## 它做什么

你给它一个装着收据图片的文件夹（JPG、PNG、PDF），它给你一份 CPA 拿到手就能开工的 Excel 底稿。

- **结构化提取** —— 商户、日期、明细、小计、税额、折扣、小费、支付方式、币种。
- **数值经过交叉校验** —— 提取结果要过勾稽算式、明细加总、税额分摊恒等式，以及所属省份的法定税率上界。过不了的会被标出来复核，而不是被悄悄"修正"。
- **GIFI 判在明细行，不判在单据** —— 一张 T&T 小票可以拆成 8523（热食柜，餐饮招待）和 8810（杂货）。这种拆分正是明细级底稿的价值所在。
- **三根轴严格分开** —— GIFI code（报表怎么归类）、税务处理（能扣多少：ITA 67.1 的 50% 上限、CCA、资本化）、可扣除性（这笔到底算不算经营支出）。明显的个人消费标 `N`，不会被包装成一笔看起来合理的营运费用。
- **全部凭证都进底稿** —— 不因为不可扣就不记录。该不该扣靠字段标注表达，CPA 因此能看到客户交来的完整凭证集。
- **字段级来源标注** —— 每个值都带来源标签，底稿任一行都能回溯到原始图片文件。CRA 审计时看的就是这条链路。

产物是一个 4 sheet 工作簿：明细、单据、原始工具输出，以及一份含 13 道质量闸门和例外清单的校验报告。

## 适用场景

加拿大小企业税务申报、CPA 工作底稿准备、收据照片批量处理。支持中、英、法三种语言的收据。

**不适用**：手写收据、非加拿大收据（税务规则不同，GIFI 不适用）、只想在对话里读一张收据（直接用视觉能力就够了）。

GIFI code 与税务处理提示都是 advisory 性质。最终的 Schedule 1 调整和可扣除性判定仍由 CPA 决定。

## 安装

克隆到你的 skills 目录：

```bash
git clone https://github.com/mebusw/invoice-canada-cpa.git ~/.claude/skills/invoice-canada-cpa
```

如果你的 skills 放在别处（比如 `~/.agents/skills/`），克隆到那里即可。

之后直接描述任务就会自动触发 —— "处理这些收据"、"提取发票数据"、"按 GIFI 给这些费用分类"、"生成费用工作底稿"。

### 运行前提

至少要有一个视觉模型可用，skill 启动时自动探测并选择模式：

| 模式 | 需要 | 行为 |
|---|---|---|
| **dual-vision** | 视觉大模型 **加上** `mineru` skill | 两个独立来源，逐字段交叉仲裁 |
| **single-vision** | 仅视觉大模型 | 单一来源，用更紧的复核阈值补偿 |

视觉模型用 `mmx` CLI（MiniMax）或 OpenAI（设置 `OPENAI_API_KEY`）都可以。两种模式产物完全相同，dual-vision 只是能拦下更多问题。

本 skill 刻意不使用本地 OCR 工具 —— 视觉模型一次就完成了 OCR、版面识别和语义理解，本地 parser 只是把其中最弱的一环重做一遍。
