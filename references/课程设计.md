AI 替你：

- ✅ 收资料 · 整理资料 · 分类资料

---

# As-Is：传统 CPA Firm 的痛点

| 环节 | 痛点 |
|---|---|
| 资料收集 | 客户资料不完整，反复催 |
| 数据录入 | 大量重复输入、分类 |
| 票据处理 | 加拿大发票格式多样，分类耗时 |
| Bookkeeping | 人工判断会计科目（住宿/餐费/机票/场地租金） |
| Review | Senior CPA 时间有限 |
| 经验传递 | 新人依赖 Senior，标准不统一 |

**资深 CPA 反馈：** 还没完全自动化的就是**原始数据录入**——格式多、票据乱、科目判断靠经验。

# As-Is 工作流（人工）

```

   ↓ Email + PDF + Excel + Receipt（散落在 Google Drive / Outlook）

   ↓ 人工下载 → OCR → 输入

   ↓
Financial Statement
   ↓
人工录入 Tax Software（ProFile / uFile / TaxPrep / TurboTax）
   ↓
Senior CPA Review
   ↓
EFILE Submission
```


> 💡 **AI 完成"前半段资料整理"，CPA 完成"后半段专业判断"**——职责清晰、不越界。

# 报税流程三层拆解（关键认知）

| 层              | 内容              | 谁来做               |
| -------------- | --------------- | ----------------- |
| **Automation** | 收集、OCR、录入前整理    | **L1 AI 员工**      |
| **Knowledge**  | Review、Planning | **L2 AI 员工**      |
| **CPA**        | 录入、判断、签字        | **CPA 本人（ProFile）** |

> 💡 **资深 CPA 洞察：** 真正需要 Knowledge 的是**录完以后**。
> AI 在 ProFile 之外完成 Review、提建议，把结构化 Working Paper 交给 CPA。

# AI Knowledge 的真正切入点

不是"AI 自动报税"，而是 **Tax Review Report**：

| 场景 | AI 输出 |
|---|---|
| T1 个人 | 客户 RRSP 还有 Deduction Room，建议不要今年全部扣，预计明年收入更高 |
| T2 公司 | Meals $5,000，提醒检查 Business Purpose，可能超过历史水平 |
| GIFI 分类 | AWS Invoice → Software Expense → GIFI 9270（Confidence 95%） |
| 异常检测 | 大额变动、缺失单据、重复交易、Capital vs Expense |

**加拿大发票格式多样——AI 处理越复杂的原始数据，价值越大。**

# ⚠️ 工具边界（课程必须说清楚）

| ✅ AI 能做                           | ❌ AI 不做（目前）              |
| --------------------------------- | ------------------------ |
| 拉取 Google Drive 文件                | 直接控制 ProFile（Windows 软件） |
| OCR + 抽取 + 分类                     | 自动填 ProFile / uFile 表单   |
| 查 Obsidian 知识库做 Review            | 触发反机器人（网页版税务软件）          |
| 生成 Markdown / Excel Working Paper | 替 CPA 签字                 |
| 起草催资料邮件                           | 替 CPA 做最终判断              |

> 💡 **AI 是 CPA 的"数字助理"，不是"机器人点击"。**
> ProFile / uFile 等 Windows 报税软件由 CPA 自己在电脑上完成。

# 三层 AI 员工定位

| Level | 定位 | 痛点 | 推荐 Demo |
|---|---|---|---|
| **L1** Automation Worker | 执行员工 | 重复劳动、票据录入、催资料 | 🧾 Receipt Assistant、📂 文件整理、📩 自动催邮件 |
| **L2** Knowledge Worker | 知识员工 | 新人经验不足、规则记不住 | 🧠 Tax Review、💰 Expense Classification、📚 GST/HST |
| **L3** Expert Worker | 专家员工 | Senior 太忙、经验无法复制 | 👨‍💼 Senior CPA Agent、📈 Tax Planning |

> **课程核心交付 L1 + L2**；L3 留给事务所用自身知识资产构建（课程教萃取方法）。
